
# E-Commerce Sales & Customer Analytics

## Project Overview
This project analyzes e-commerce data to understand sales performance, profitability, customer behavior, product returns, and marketing channel performance using Python.

## Objectives
- Analyze sales and profit performance.
- Understand customer segments and purchasing behavior.
- Evaluate product returns and marketing channels.
- Identify business trends and actionable insights.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## Project Workflow
1. Data inspection and exploration
2. Data cleaning and validation
3. Feature engineering
4. Exploratory Data Analysis (EDA)
5. KPI analysis and data visualization
6. Business insights and conclusions

## Key Findings
- Analyzed over 138,000 e-commerce records.
- Observed an overall return rate of approximately 6.85%.
- Compared customer segments, sales channels, regions, and marketing sources.
- Examined profitability and customer purchasing patterns.

## Project File
- `E-Commerce Sales And Customer Analytics Project (Cleaned).ipynb` — notebook containing the analysis.

## Conclusion
The analysis explores e-commerce sales, profitability, customer behavior, and returns to identify patterns that can support data-driven business decisions.
